===============================================================================

                    DEVELOPER SETUP & GUIDELINES

===============================================================================



This document provides developer guidelines, environment setup steps,

and critical folder/path structure rules required to run CyberSentinel properly.



-------------------------------------------------------------------------------

1. ENVIRONMENT SETUP (.env)

-------------------------------------------------------------------------------

- Create a `.env` file in the root directory of the project (`major/.env`).

- Add your Google Gemini API key:

      GEMINI_API_KEY="your_actual_gemini_api_key_here"



- Note on API Key mapping:

  The `risk_assessment.py` and LangChain workflow dynamically map

  `GEMINI_API_KEY` to `GOOGLE_API_KEY` if not already set. However, maintaining

  `GEMINI_API_KEY` in `.env` is required for the LLM agentic modules.



-------------------------------------------------------------------------------

2. DIRECTORY & PATH STRUCTURE (CRITICAL)

-------------------------------------------------------------------------------

To prevent file-not-found errors across Streamlit pages, preserve the repository

folder structure exactly as cloned:



major/

│

├── .env                              <- API Keys

├── app.py                            <- Main Entry Point (Dashboard)

├── requirements.txt                  <- Dependencies

├── instructions.txt                  <- Developer Guidelines

│

├── data/

│   └── cleaned_cicids2017.parquet    <- Preprocessed dataset (can be downloaded from github releases section)

│

├── outputs/                          <- Output folder for all ML/Graph outputs

│   ├── attack_events.csv

│   ├── attack_graph.gexf

│   ├── event_risk_scores.csv

│   ├── suspicious_flows_with_metadata.csv

│   └── pipeline_summary.json (optional)

│

├── pages/                            <- Streamlit Multi-Page UI

│   ├── attack_detection.py           <- Anomaly detection preview

│   ├── attack_graph.py              <- Interactive attack graph network

│   ├── incident_investigation.py     <- Event & incident details

│   └── risk_assessment.py            <- Triage & Agentic AI investigation

│

└── agent/                            <- LangGraph AI Agent & Workflows

    ├── workflow.py

    └── tools/



-------------------------------------------------------------------------------

3. FILES TO MODIFY IF YOU CHANGE FILE/FOLDER PATHS

-------------------------------------------------------------------------------

If you rename folders or output CSV/GEXF files, you MUST manually update the

path constants defined at the top of these specific files:



a) `pages/attack_detection.py`

   - Path definitions: `OUTPUT_DIR = ROOT / "outputs"`

   - Target files: `suspicious_flows_with_metadata.csv`, `pipeline_summary.json`



b) `pages/attack_graph.py`

   - Path definitions: `OUTPUT_DIR = ROOT / "outputs"`

   - Target files: `attack_graph.gexf`, `attack_events.csv`



c) `pages/incident_investigation.py`

   - Path definitions: `OUTPUT_DIR = ROOT / "outputs"`

   - Target files: `attack_events.csv`



d) `pages/risk_assessment.py`

   - Target files: `outputs/event_risk_scores.csv`, `outputs/suspicious_flows_with_metadata.csv`



e) `app.py`

   - Path definitions: `OUTPUT_DIR = ROOT / "outputs"`, `DATA_PATH = ROOT / "data" / ...`



-------------------------------------------------------------------------------

4. HOW TO RUN THE PROJECT

-------------------------------------------------------------------------------

1. Install Python 3.10+ and set up a virtual environment:

      python -m venv venv

      source venv/bin/activate   # On Linux/Mac

      venv\Scripts\activate      # On Windows



2. Install dependencies:

      pip install -r requirements.txt



3. Execute the Streamlit application from the root directory (`major/`):

      streamlit run app.py



-------------------------------------------------------------------------------

5. DEVELOPER CAUTIONS & COMMON ERRORS

-------------------------------------------------------------------------------

- ALWAYS run `streamlit run app.py` from the project ROOT folder,

  NOT from within the `pages/` directory.

- `suspicious_flows_with_metadata.csv` can be quite large. `attack_detection.py`

  uses `nrows=100_000` preview loading to preserve system RAM during dashboard rendering.

- Ensure `attack_events.csv` contains headers matching backend conventions:

  `_id` or `event_id`, `src_ip`, `dst_ip`, `protocol`, `attack_type`, `flow_count`.
